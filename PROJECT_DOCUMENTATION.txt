Meta Lead Automation SaaS - Technical Documentation

1. Project Overview
-------------------
Name: Meta Lead Automation SaaS
Objective: An enterprise-grade RPA (Robotic Process Automation) and AI platform designed to automate the entire lead lifecycle from acquisition to conversion.
Core Value: Transforms static lead databases into active, intelligent sales engines using "Neural Agents".

2. System Architecture
----------------------

Tech Stack:
- Frontend: React.js (Vite), Tailwind CSS, Lucide Icons.
- Backend: Node.js, Express.js.
- Database: MongoDB (Mongoose ORM).
- AI Engine: OpenAI (GPT-4), Vapi.ai (Voice Intelligence).
- Communication: SendGrid (Email), Facebook Graph API (WhatsApp & Leads).
- Payments: Stripe (Subscription Management).

Key Directory Structure:

3. Core Features & "Neural Agents"
----------------------------------

1. The Automation Engine (server/services/automationService.js)
- Workflow Builder: A drag-and-drop interface for creating custom logic flows.
- Swarm Intelligence: Different agent types (Voice, Spy, Profiling) coordinate actions based on workflow nodes.
- Resilience: Features detailed error handling and circuit breaker patterns.

2. Instant Voice Agent (server/services/voiceService.js)
- Integration: Vapi.ai
- Function: Triggers a phone call immediately upon lead creation.
- Capability: Speaks with human-like intonation, qualifies leads, and updates the database with call status.

3. Competitor Intelligence Spy Bot (server/services/intelligenceService.js)
- Integration: OpenAI
- Function: Analyzes lead email domains to infer company details.
- Output: Generates a "Sales Battlecard" identifying top 3 competitors and winning strategies.

4. Psychological Profiling (server/services/profilingService.js)
- Integration: OpenAI
- Function: Predicts DISC personality type based on job title and available data.
- Output: Provides communication tips (e.g., "Be direct with Type D").

5. Predictive Revenue Modeling (server/services/revenueService.js)
- Function: Estimates the Lifetime Value (LTV) of a lead.
- Logic: Uses heuristical data (Company Size, Industry) to assign a dollar value.

4. Key Database Models
----------------------

Organization Model:
The central tenant entity. Stores:
- API Keys: Encrypted keys for Vapi, OpenAI, SendGrid.
- Subscription: Stripe status and plan level.
- Branding: Custom logos and email settings.

Lead Model:
The core data entity. Enhanced fields include:
- leadScore & scoreReason (AI Qualifiction)
- voiceCallStatus (Call tracking)
- competitors & salesBattlecard (Intelligence data)
- discProfile (Psychological metadata)
- predictedRevenue (Financial forecasting)

5. Security & Configuration (Frontend Managed)
----------------------------------------------
All sensitive configurations are managed via the Settings Page:
- Dynamic Key Injection: Users enter their own API keys (Vapi, OpenAI), which are stored securely in their Organization document.
- Audit Logging: Sensitive actions are tracked in a secure audit log.

6. How to Run
-------------

Backend:
1. Open terminal in 'server' folder.
2. Run 'npm install'
3. Run 'node server.js'
(Runs on localhost:4000)

Frontend:
1. Open terminal in 'client' folder.
2. Run 'npm install'
3. Run 'npm run dev'
(Runs on localhost:5173)
