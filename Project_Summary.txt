CORE TECH STACK
-------------------------------------------------
[Frontend]
- Environment: Vite (Fast Build Tool)
- Library: React 18
- Language: JavaScript (ES6+)
- Styling: Tailwind CSS 3 (Utility-first framework)
- UI Icons: Lucide React
- Routing: React Router 6
- State/Data: Axios (API calls)
- Visualizations: 
    - React Flow (Drag-and-Drop Workflow Builder)
    - Recharts (Analytics Charts)
- Real-time: Socket.io Client

[Backend]
- Runtime: Node.js
- Framework: Express.js
- Database: MongoDB (with Mongoose ODM)
- Authentication: JWT (JSON Web Tokens) with BCrypt hashing
- Real-time: Socket.io
- Security: Helmet (Headers), Express Rate Limit (DDoS protection), XSS Clean, Mongo Sanitize
- File Uploads: Multer (for Logo/Media)
- Email: Nodemailer / SendGrid (ready for integration)

KEY FEATURES IMPLEMENTED
-------------------------------------------------
1. ROBOTIC PROCESS AUTOMATION (RPA) ENGINE 🤖
   - Visual Workflow Builder: Drag & drop interface to design automation flows.
   - Node Types: Trigger (Lead Created), Actions (Email, WhatsApp), Logic (Condition), Helpers (Wait).
   - "Smart" Branching: True If/Else logic based on Lead Score, Status, etc.
   - Circuit Breaker: Automatically stops automation if 5+ failures occur to prevent spam/server crash.
   - Version Control (Git-Style): Commit history, Rollback to previous versions, Draft vs. Live modes.
   - Mock Testing: Ability to verify workflows with fake lead data without spending ad money.

2. AI LEAD SCORING 🧠
   - Intelligent analysis of incoming leads.
   - Assigns a score (0-100) based on lead quality/data.
   - Provides "Reasoning" for the score (e.g., "High intent detected", "Missing phone number").

3. SAAS & MULTI-TENANCY 🏢
   - Organization Support: Every user belongs to an Organization.
   - Role-Based Access Control (RBAC):
       - Super Admin: Can manage everything.
       - Admin: Can manage their Organization & Team.
       - User: Restricted access (Leads only).
   - Team Management: Invite members via email, revoke access.

4. LEAD MANAGEMENT SYSTEM 📋
   - Central Dashboard: View all leads in real-time (Socket.io updates).
   - filtering: By Status (New, Contacted, Interested, etc.).
   - Assignment: Assign leads to specific sales team members.
   - Bulk Actions: Delete multiple leads at once.
   - Export: Download leads as CSV.

5. SETTINGS & CUSTOMIZATION ⚙️
   - Branding: Upload Company Logo, Change Company Name.
   - User Profile: Update Name, Email, Password.
